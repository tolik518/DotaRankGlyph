# Put the Glyph Matrix SDK here

Download `glyph-matrix-sdk-2.0.aar` from Nothing's developer kit and place it in this folder:

https://github.com/Nothing-Developer-Programme/GlyphMatrix-Developer-Kit

The file name must be exactly `glyph-matrix-sdk-2.0.aar` (or update `app/build.gradle.kts`).
It isn't bundled because the Glyph SDK licence doesn't allow redistribution.
